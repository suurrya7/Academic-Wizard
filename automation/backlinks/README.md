# Backlink Automation Setup

This directory contains the script to automatically publish AI-generated backlinks across 7 platforms.

## Credentials Required

You must configure these GitHub Repository Secrets:

| Secret Name | How to Get It |
|:---|:---|
| `GEMINI_API_KEY` | Already configured (used by `generate_post.py`) |
| `GH_PAT` | GitHub → Settings → Developer Settings → PAT → `repo` scope |
| `DEVTO_API_KEY` | Dev.to → Settings → Extensions → Generate API Key |
| `WP_USERNAME` | WordPress.com → Username |
| `WP_APP_PASSWORD` | WordPress.com → Users → Profile → Application Passwords |
| `WP_SITE_URL` | Your WordPress site URL (e.g., `https://yourblog.wordpress.com`) |
| `TUMBLR_CONSUMER_KEY` | [Tumblr OAuth Apps](https://www.tumblr.com/oauth/apps) |
| `TUMBLR_CONSUMER_SECRET` | [Tumblr OAuth Apps](https://www.tumblr.com/oauth/apps) |
| `TUMBLR_ACCESS_TOKEN` | [Tumblr OAuth Apps](https://www.tumblr.com/oauth/apps) |
| `TUMBLR_ACCESS_SECRET` | [Tumblr OAuth Apps](https://www.tumblr.com/oauth/apps) |
| `GOOGLE_CLIENT_ID` | Google Cloud Console → Blogger API → OAuth Client |
| `GOOGLE_CLIENT_SECRET` | Google Cloud Console → Blogger API → OAuth Client |
| `GOOGLE_REFRESH_TOKEN` | [OAuth Playground](https://developers.google.com/oauthplayground) with `access_type=offline` |
| `BLOGGER_BLOG_ID` | Your Blogger blog ID (from URL) |
| `LINKEDIN_ACCESS_TOKEN` | LinkedIn Developer Portal → "Share on LinkedIn" product |
| `LINKEDIN_REFRESH_TOKEN` | LinkedIn Developer Portal → "Share on LinkedIn" product |
| `LINKEDIN_CLIENT_ID` | LinkedIn Developer Portal → "Share on LinkedIn" product |
| `LINKEDIN_CLIENT_SECRET` | LinkedIn Developer Portal → "Share on LinkedIn" product |
| `PINTEREST_ACCESS_TOKEN` | Pinterest Developers → Submit for Standard Access |
| `PINTEREST_REFRESH_TOKEN` | Pinterest Developers → Submit for Standard Access |
| `PINTEREST_CLIENT_ID` | Pinterest Developers → Submit for Standard Access |
| `PINTEREST_CLIENT_SECRET`| Pinterest Developers → Submit for Standard Access |
| `TELEGRAPH_ACCESS_TOKEN`| Auto-generated by calling `https://api.telegra.ph/createAccount` |
